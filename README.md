# Loading Screen Gold: A Tip in 200 Characters

A single sharp, funny loading-screen tip for stressed developers and AI coding agents — 93 characters, one line. Entry for the [make.fun bounty](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270).

## Run

```sh
node main.ts
```

Writes the tip to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
